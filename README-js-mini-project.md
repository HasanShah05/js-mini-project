# JS Mini Projects

A collection of small JavaScript projects built to practice core web development concepts — DOM manipulation, APIs, animation, and interactive UI logic.

## 📁 Projects Included

| Project | What it does |
|---|---|
| `bmi calculator` | Calculates Body Mass Index from user height/weight input |
| `color changer` | Changes background color dynamically on user interaction |
| `countries` / `country visualization` / `country visualization2` | Fetches and displays country data, with visualizations |
| `digital clock` | Real-time digital clock built with JavaScript |
| `guess number` | Number-guessing game with win/lose logic |
| `leaderboard` | Displays and sorts a ranked leaderboard |
| `no generator` | Random number generator app |
| `animating character` | CSS/JS-based character animation |
| `solar system` | Animated visualization of the solar system |
| `portfolio` | Personal portfolio site build |
| `first project` | Intro JavaScript exercise |

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (no frameworks)

## 🚀 Getting Started

Each folder is a self-contained mini-project.

```bash
git clone https://github.com/HasanShah05/js-mini-project.git
cd js-mini-project/"bmi calculator"
```

Then simply open `index.html` in your browser — no build step required.

## 💡 Why this repo

This repo tracks my progress learning core JavaScript by building small, focused apps rather than tutorials-only — each folder targets a specific concept (DOM events, fetch/APIs, animation, game logic).
